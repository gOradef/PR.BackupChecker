## What is it?
Данный репозиторий содержит исходный код утилиты, которая следит за наличием бэкапов данной организации. 

## How?
1. Программа обходит хост(ы) на наличие файлов расширения бекапов. При нахождении подобных, путь к нему сохраняется в конфиг и используется в дальнейшем.
2. Происходит обход по путям, где находятся бэкапы и сверяется текущая даты системы с последним изменением файла.
3. В зависимости от последней даты созданного бекапа создается соответсвующая запись в отчете.
4. При отсутсвии бекапы, отправляется уведомление в Zabbix организации для дальнейшего устранения.
